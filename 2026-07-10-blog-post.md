# Hello, World! 👋

Welcome to my brand new blog hosted on GitHub Pages! I am using this space to document my learning journey, share my projects, and write about things that interest me.

## Why I'm starting this blog
I wanted a simple, fast, and customizable way to share my thoughts online. By using GitHub Pages combined with Jekyll and the **minima** theme, I can write everything in plain Markdown and let GitHub handle the hosting for free.

## What to expect next
Moving forward, I plan to write about:
- 💻 Web development and coding tips
- 🧠 New skills and technologies I'm learning
- 🚀 Updates on personal projects

Thanks for stopping by! Stay tuned for more updates soon.
